# Koru

Use this repository to run and edit the app locally as a standalone Vite app.

## Prerequisites

1. Clone the repository using the project's Git URL.
2. Navigate to the project directory.
3. Install dependencies: `npm install`.

## Run Locally

Run the frontend from the project root:

```bash
npm run dev
```

Open the local URL printed by Vite.

The app stores its data locally in the browser. No Base44 environment variables are required.

## Build

```bash
npm run build
```
